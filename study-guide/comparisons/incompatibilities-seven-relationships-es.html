Mapa de las Siete Relaciones

Qī Qíng (七情) describe lo que ocurre cuando las sustancias medicinales se encuentran dentro de una fórmula.

Mapa en una línea

Orden para recordarSolista → gemelos → ayudante → la tóxica teme → la protectora suprime → se debilita el efecto → combinación peligrosa.
Distinción rápidaMás efecto: Xū/Shǐ. Menos toxicidad: Wèi/Shā. Menos efecto: Wù. Más riesgo: Fǎn.

Las siete y sus sinónimos de examen

RelaciónEtiquetas frecuentesEjemplo ancla
Dān Xíng 单行Efecto individual; una sustancia actúa sola.Rén Shēn sola en Dú Shēn Tāng.
Xiāng Xū 相须Necesidad mutua / acentuación mutua; acciones similares se refuerzan.Shí Gāo + Zhī Mǔ.
Xiāng Shǐ 相使Empleo mutuo / potenciación mutua; ayuda con acción distinta.Huáng Qí + Fú Líng para edema por deficiencia.
Xiāng Wèi 相畏Temor mutuo / contrarresto mutuo; se doma la hierba tóxica.Bàn Xià “teme” a Shēng Jiāng.
Xiāng Shā 相杀Eliminación mutua / supresión mutua; la protectora suprime toxicidad.Shēng Jiāng suprime la toxicidad de Bàn Xià.
Xiāng Wù 相恶Aversión mutua / antagonismo mutuo; una debilita el efecto de otra.Lái Fú Zǐ debilita el énfasis tonificante de Rén Shēn.
Xiāng Fǎn 相反Oposición mutua / incompatibilidad mutua; la combinación aumenta daño.Los grupos Shí Bā Fǎn.

Marco de seguridad

Son términos históricos y conocimiento requerido para examen. No sustituyen identidad exacta, procesamiento, dosis, conciliación de medicamentos ni toxicología actual.
