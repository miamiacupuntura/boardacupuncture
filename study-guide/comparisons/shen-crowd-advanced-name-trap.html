The Shēn Group: One Sound, Many Roots

Shēn is not a botanical family: it labels Qi tonics, Yin tonics, Heat-clearers and a Blood mover.

Memory rule

AnchorRén/Xī Yáng/Dǎng/Tài Zǐ = Qi; Shā = Yin; Xuán/Kǔ = Heat; Dān = Blood.

Exam and safety

Exam keyNever swap Dǎng Shēn (Qi) and Dān Shēn (Blood).
SafetyClassical sources list the Shēn group as incompatible with Lí Lú. Dān Shēn requires anticoagulant/bleeding screening.
