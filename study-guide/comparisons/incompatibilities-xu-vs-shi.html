Xiāng Xū vs. Xiāng Shǐ

Both are useful synergy, but the division of labor is different.

Fast distinction

Xiāng Xū 相须“Twins”: similar functions reinforce the same therapeutic job.
Xiāng Shǐ 相使“Principal + helper”: different functions cooperate, with one assisting the main action.

Examples

PairRelationshipWhy
Shí Gāo + Zhī MǔXiāng XūBoth intensify clearing of strong Qi-level Heat.
Dà Huáng + Máng XiāoXiāng XūBoth drive a purgative strategy in the Chéng Qì family.
Jīng Jiè + Fáng FēngXiāng XūBoth release the Exterior and expel Wind.
Huáng Qí + Fú LíngXiāng ShǐHuáng Qí tonifies Qi so fluids move; Fú Líng drains Dampness.
Zhī Mǔ + Huáng BǎiXiāng ShǐDifferent but complementary actions target Lower-Jiao deficiency Heat.

Exam prompt

If both herbs independently perform the named main action, choose Xū. If the question identifies a main herb and a different-action assistant, choose Shǐ.
